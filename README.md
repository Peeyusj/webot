# BatChat Extension (Frontend) 🦇

BatChat is a local-first Manifest V3 (MV3) Chrome extension that turns any web page or documentation site into a strict, grounded RAG (Retrieval-Augmented Generation) chat assistant. 

This repository contains the React UI, the content extraction engine, and the background service worker acting as the network broker.

## 🏗 Architecture & Engineering Highlights

* **Client-Side Extraction (The Auth Bypass):** Instead of relying on server-side bots that get blocked by Cloudflare or login walls, the extension uses a hybrid extraction engine (Mozilla Readability + custom semantic fallback) to read the live DOM. This allows it to RAG over private Jira tickets, gated articles, and local staging servers seamlessly.
* **Shadow DOM Isolation:** The React app and Tailwind CSS are injected into the host page within an open Shadow DOM, ensuring zero CSS bleed between the extension and the host website.
* **Stateless BYOK (Bring Your Own Key):** API keys are sandboxed securely in `chrome.storage.local`. They are never exposed to the host page DOM and are sent only as per-request headers to the backend.
* **Service Worker Network Broker:** To bypass MV3 Content Security Policy (CSP) and CORS restrictions, all backend fetching and Server-Sent Events (SSE) streaming are centrally routed through the `background.js` service worker.

## 🛠 Tech Stack

* **Framework:** React 18
* **Language:** TypeScript 5
* **Styling:** Tailwind CSS v4 (inline compiled)
* **Build Tool:** Vite (with static copy plugins for MV3 compatibility)
* **Content Parsing:** `@mozilla/readability`

## 🚀 Getting Started

### Prerequisites
* Node.js (v18+ recommended)
* npm or yarn

### Installation & Build

1.  Clone the repository and install dependencies:
    ```bash
    npm install
    ```
2.  Build the extension:
    ```bash
    npm run build
    ```
    *Note: The Vite build process outputs a single `content.js` and copies the `manifest.json`, background scripts, and assets directly into the `dist` (or `build`) folder.*

### Loading into Chrome
1.  Open Chrome and navigate to `chrome://extensions/`.
2.  Enable **Developer mode** in the top right corner.
3.  Click **Load unpacked** and select the `dist` directory generated by the build step.
4.  Pin the extension to your toolbar and click to open the side panel.
